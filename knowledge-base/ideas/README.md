# Strategy idea cards

There is one card per idea: `<short-name>.md`. Status is one of: **untested → testing →
passed / failed / not testable**. A card's rules are fixed when it is created. If the rules
change later, that change is recorded as a new version on the card.

```
## Why it might work (cause)
## Similar ideas already tested   -> link to knowledge-base/strategies/...
## Test plan   -> data available? which tool (bots/spec10 engine, bots/edge)?
## Result      -> filled after the test
```
