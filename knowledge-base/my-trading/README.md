# My trading: what the user's own trades show

Reports are made by `python -m bots.kb.trades report <csv>`. They contain facts only
(results by market, session, weekday, holding time, R, and process flags). The lessons
drawn from them go into `knowledge-base/LESSONS.md` under "My trading", each with a link to
the report it came from.

Under about 30 trades, a pattern is a question to watch, not a rule.
