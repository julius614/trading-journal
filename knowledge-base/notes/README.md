# Notes: things the user pasted for Claude to learn from

There is one file per source: `YYYY-MM-DD-short-title.md`. Each file holds a summary and
the key points, never a full copy (this repo is public). Template:

```
# <Title>
**Source & capture:** <link or "pasted by user", author, date>; read in full / excerpt.
**Type:** article | video | book | course | AI answer | own experience
**Tags:** strategy, risk, psychology, macro, forex, gold, indices, prop-firm, tools ...
**Evidence level:** RESEARCH (peer-reviewed / data) | CLAIM (opinion, marketing, untested) | USER (your own experience)

## Summary (5 lines max)
## Key points
## Claims we could test   -> becomes an idea card in ../ideas/ if worth testing
## How it fits what we already know   -> agrees with / contradicts LESSONS.md items
```
